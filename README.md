# Nova's Realm

**Collaborative Adventure Game**

An immersive collaborative adventure game where human and AI players work together to explore, build, and solve coding challenges in the mystical CodeQuest Academy.

## Core Features
- Dual Player System: Seamlessly blend human creativity with AI intelligence
- Coding Powers: Programming concepts manifest as magical abilities
- Collaborative Building: Teams work together to solve complex challenges
- Browser Visualization: Rich visual reppresentation of the game world
- Codexia's Guidance: AI mentor with ElevenLabs voice synthesis
- Knowledge Integration: MCP tools for dynamic game mechanics

## Status
Complete. Built as a collaborative AI gaming experiment.

## Portfolio role

**LAB.** Nova's Realm explores human + AI collaboration inside a game/learning world. It is intentionally experimental and should share learning/progression primitives with the educational game projects rather than grow its own incompatible framework for every feature.

## Project context

This is a personal, self-directed learning project by João Caldas. I learn game development and software engineering by building playable systems, studying failures, refactoring experiments, and comparing different approaches.

AI tools are used extensively during research, design, coding, debugging, testing, asset ideation, and documentation as part of that learning process. AI-generated suggestions are treated as inputs to review, not proof of correctness. Gameplay behavior, persistence, security/privacy boundaries, and technical claims should be tested and documented.

## AI integration boundary

The current browser experience contains experimental/simulated AI-authentication and voice-integration code. It does not ship a browser ElevenLabs API key, and browser speech is used as a fallback.

The current token-style authentication experiment should be treated as a learning prototype, not as a production OAuth/security reference. Any future real provider integration should use the provider's current authorization guidance and avoid exposing durable secrets in public browser code.
